# Torre Toscana · cbarrera.com

Sitio web de Torre Toscana. Hostinger lo publica en `public_html` desde la rama `main`.

- `index.html` — página principal
- `img/` — imágenes
- `disponibilidad/` — redirige a la página de disponibilidad en vivo
- `toscana/` — brochures, videos y página para enviarlos por WhatsApp
